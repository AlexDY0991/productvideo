# CoolFly 设计简报

先想清楚「放在哪、给谁看、要达成什么」，再动手。好不好看是最后一步的判断，不是第一步。

## 什么时候用哪一版

| 版本 | 适用 | 做法 |
|---|---|---|
| **简版**（3 行） | 改已有物料、单张社媒图、封面图、同系列延展 | 在回复里写三行：场景/观众、目的、关键信息。没问题就直接做，做完说明依据 |
| **完整版** | 新物料、新系列、展会、手册、PPT、对外重要物料 | 写完整简报 + 1–2 个方向，用户确认后再做精细稿 |

拿不准就用完整版。用户给的信息不够时，先问，不自己编文案、参数或事实。

## 完整简报的六项

1. **场景**：在哪里出现、尺寸/媒介、观看距离、停留时间（一瞥 / 站定 / 翻阅 / 手机滑过）。
2. **观众**：是谁、对 CoolFly 了解多少、他们关心什么。
3. **主目的**：只选一个——吸引注意、认出品牌、理解产品、建立信任、促成行动（扫码、留资、预约）。
4. **信息层级**：按「第一眼 / 第二眼 / 细看」列出，每层一句话。只写用户给的或 `HANDOFF.md` 里有的数据。
5. **环境与系统**：遮挡、周边物料、同场其他物料、品牌一致性（logo、橙色、字体、画面风格）。
6. **方向**：1–2 个方向，各用一句话 + 小草图或参考说明取舍，让用户选。

## 各类物料的默认考量

| 物料 | 关键判断 |
|---|---|
| **展台背景墙** | 空间的一部分，不是放大的海报。10 m 外认品牌（logo + 一句品类），2 m 内讲产品；下部 0.9–1 m 常被人和展台挡住；可当拍照背景；有真机时给真机让位 |
| **展台正面 / 桌牌** | 近距离、几秒钟。品牌 + 一句话 + 联系方式；桌牌讲清一个产品点 |
| **海报 / 邀请函** | 一张讲一件事。邀请函重信息完整（时间、地点、展位）；品牌海报重记忆点，信息精简 |
| **产品手册** | 翻阅、可带走。先定章节结构和叙事顺序，再做版式系统（网格、字级、图片规范）；参数页准确优先 |
| **PPT** | 讲述的辅助，一页一个观点。先确认场合（路演 / 合作洽谈 / 发布）、时长、讲者，再写故事线和页纲，最后视觉 |
| **封面图 / 社媒图** | 小尺寸、手机滑过 1 秒。主体大、文字少、缩略图里也能看清；注意平台尺寸和安全区 |
| **名片** | 拿在手里细看。信息清楚、留白、和品牌系统一致；双面可分担内容 |

## 品牌基线

- 画面文字一律英文；人物尽量真实。
- CoolFly 橙 `#FF5A00` 为主色；logo 用 `brand/coolfly-logo.svg`，F 为橙色。
- Dream / Urban 外形以 `brand/models/*.glb` 和参考图为准；产品参数只用 `HANDOFF.md` 第 1 节表格。
- 出图后自查（结构、文字拼写、logo、桨叶数量等），再交付。
