## 1. 无人之梦

- **链接**：https://app.tapnow.ai/tapflow/view/f844cbf1
- **内容**：一战风格的架空战争。A 阵营士兵反复梦见敌方士兵 B，现实与梦境交替，渡鸦贯穿全片。
- **规模**：234 节点。MJ v8.2 出空镜 44 次，Gemini Pro 精修 18 次，Seedance 2.5 出视频 44 次。
- **画布布局**：最左是资产库（服装、人物三视图、道具），中间是空镜（每个场景 try1–try10），右侧按段落排视频，底部是音频。
- **最值得学**：
  - 人物的脸和服装分开锁定
  - 空镜预留表演空间
  - 六段式视频提示词：概述 / 素材职责 / 背景与表演 / 空间光线镜头 / 时间轴 / 声音
  - 表情写成肌肉动作
  - 用虚构语言写台词
  - 把转场写进提示词（穿烟进梦、横移硬切）
  - 先用五个模型跑同一条提示词，再选定 Seedance 2.5
- **质感问题**：鸟瞰空镜偏数字绘景；钢盔没做资产，被画成德军样式。

## 2. 最后的问题

- **链接**：https://app.tapnow.ai/tapflow/view/45a850a3
- **内容**：改编阿西莫夫《最后的问题》。不同时代的人类，加上超级 AI "AC"（分形立方体，可变成多种形态）。21:9。
- **规模**：489 节点。Seedance 2.5 草稿版 97 次，Kling 4.0 62 次，Seedance 2.5 正式版 51 次。
- **最值得学**：
  - 真实感前缀和"制造不对称"的人物写法
  - 固定的人物资产板版式
  - 身份和光线分开锁定（"严禁继承资产图的棚拍光"）
  - 9 段式视频提示词，其中 VISUAL RULE 一段用物理机制描述效果
  - 先出草稿再出正片
  - 按镜头长短分工：Kling 做 4–6 秒精确镜头，Seedance 做长段落
  - 用视频模型生成纯人声作为音色锚点
  - 复杂主体先做形态总表
- **质感问题**：一条 Kling 大场面里出现光速穿梭特效；一条 4 秒蒙太奇里漏出资产图的灰底人脸。

## 3. KILL A

- **链接**：https://app.tapnow.ai/tapflow/view/dca46143
- **内容**：黑客松作品。风格化 3D 动画惊悚片，一对双生姐妹（橙发 Mia、白发 Aria）互相残杀。21:9。
- **规模**：681 节点。Seedance 2.0 出视频 284 次（720p，15 秒）；图片主要用 gpt-image-2 和 MJ。
- **最值得学**：
  - 风格先探索（2D 赛璐璐）再统一（冷陶瓷油光 3D）
  - 画框标注摆放人物
  - 每个场景有独立主色（红色厕所、黄绿杂物间、粉紫黄昏）
  - 分镜清单版视频提示词，结尾固定"说明"段
  - 每个角色一段音色音频，几十条视频复用
- **质感问题**：15 秒写了 15 个镜头，只出来一半；片名拼错，印进了海报。

## 4. 周杰伦 TVC

- **链接**：https://app.tapnow.ai/tapflow/view/46bd47be
- **内容**：商业广告。实拍（周杰伦在客厅"空气开车"）转 80 年代赛璐璐动画（雪夜山路漂移，法拉利 288 GTO）。
- **规模**：1175 节点，Gemini Pro 出图 1092 张（大部分是一句话的精修）；视频很少，都是 4–5 秒单镜头。
- **最值得学**：
  - 3D 灰模 Layout 转 AI 关键帧，构图完全由人控制
  - 小步精修到 v011，每次只改一处
  - 专业命名：`MTZJL_SC01_C004_AI_v011`
  - 实拍画面做首帧 / 尾帧，衔接实拍和动画
  - 关键帧出绿幕，便于合成
  - 放大后再生成视频
- **质感问题**：AI 二维动画太顺滑；不同视频模型差异很大（Sora 车身变形，Wan 加雨）。
- **注意**：真人明星形象需要肖像授权。

## 5. 去有风的地方

- **链接**：https://app.tapnow.ai/tapflow/view/18ced6e8
- **内容**：上海城市宣传片。主线是一个青年早上出门，城市随之开花，加上太极、滑板、跑步等群像。
- **规模**：120 节点。Gemini Pro 出图 66 次，Kling O1 出视频 32 次。
- **值得学**：
  - 四宫格选镜头再提取
  - 用一个视觉母题（蝴蝶加花瓣、沿途开花）串起所有段落
  - 用实景照片作为环境参考
- **反面教材**：
  - 每条都堆"电影思维、导演思维、电影质感、电影运镜"，几乎没有作用
  - 写了"时间是早上 08:30"，画面里印出了时间戳
  - 橘猫中途消失，人物被裁掉头
  - FPV 鱼眼畸变严重，蝴蝶 CG 感强

## 6. RACER 18

- **链接**：https://higgsfield.ai/zh/@racer18/projects/racer-18
- **平台**：Higgsfield（不是 TapNow）。视频用 Higgsfield 自家的 Cinema Studio 4.0，图片用 gpt-image-2。
- **内容**：AI 摩托赛车电影，加爱情线和搞笑的狗角色。
- **规模**：207 条生成记录：视频 146 条，图片 61 张，约 2 万积分。
- **最值得学**：
  - **命名资产系统**：一个角色的每套服装各存一个资产（`leo-kurta`、`leo-dubai-a`、`maya-honbok`），场景、车辆也存成资产，提示词里按名字引用
  - **换装流程**：角色资产 + 完整服装描述，用 gpt-image-2 生成后另存；服装描述常从参考照片反推
  - **车辆六视图**：带文字标注的左、右、前、后、顶、前 3/4 视图。同一辆摩托在多个镜头里外形都很稳
  - 视频提示词用英文，按时间分段，开头写"Preserve X consistently throughout"，结尾分 FACIAL EXPRESSIONS / CINEMATOGRAPHY / LIGHTING / AUDIO 几段
- **质感问题**：
  - 卡车坡道飞跃那一镜，车太小，在半空悬停好几帧
  - 大量真实品牌（奔驰夹克、LV 耳环、古驰花纹），商业项目有侵权风险
  - 浮夸的 Z 世代风格，克制感不如 TapNow 那几个电影画布
- **成片拆解**：297 秒、107 个镜头，平均每个镜头 2.8 秒，一半不到 1.8 秒。结构是：片名 → 隧道英雄镜头 → 卡车飞跃 → 手机围观 → 雪山章节 → 秘鲁章节 → 派对 → 搞笑的狗 → 爱情蒙太奇 → 机器人和媒体狂欢 → 印度章节 → 反派总部 → 摩纳哥撞车（童年创伤）→ 导师砸头盔 → 合影 → "18 种语言上映"片尾。146 条生成大多是 10–20 秒的多镜头素材，剪辑时每条只用 1–3 秒。详细方法见 `08-product-brand-film.md`。
- **分析方法**：Higgsfield 的公开项目页也能抓。成片走 HLS 流，地址在播放器加载时的 `index_480p.m3u8` 请求里，用 ffmpeg 下载后做镜头切换检测（`select='gt(scene,0.32)'`）就能拆出每个镜头。页面加载时会请求 `fnf-api-gw.higgsfield.ai/fnf/folders/<文件夹ID>/items/v2`，返回每条生成记录的提示词、参数、引用的资产和成片链接，可以按 cursor 翻页拿全。

## 7. 如何分析一个新画布

需要 Node + Playwright、Python 3（含 Pillow）、ffmpeg。

```bash
# 1. 抓取画布数据
node scripts/tapgrab.js https://app.tapnow.ai/tapflow/view/<ID> work/<ID>
# 2. 导出可读的提示词清单（含模型统计和参考关系）
python3 scripts/tapdump.py work/<ID>/canvas.json work/<ID>/dump.txt
# 3. 按关键词找定稿节点（✅、SC_、版本号等）
python3 scripts/tapnodes.py work/<ID>/canvas.json "✅|SC_|_v0" image,video
# 4. 取出这些节点的媒体链接，再用 curl 下载
python3 scripts/tapmedia.py work/<ID>/canvas.json n18,n34,n218:video
# 5. 视频抽帧拼成网格、图片拼成对比图，然后直接看
bash scripts/vframes.sh in.mp4 out.jpg 8
python3 scripts/sheet.py out.jpg 3 700 a.jpg b.jpg c.jpg
```

分析时看这几件事：
1. **结构**：画布怎么分区，资产、空镜、视频、音频各放哪里，用了什么命名和标记。
2. **模型统计**：每种模型用了多少次，就能看出作者的主力模型和分工。
3. **定稿节点**：带 ✅ 的、版本号最高的、被视频引用最多的图，就是作者最终认可的资产。
4. **最长的提示词**：通常是作者打磨最多的，结构最完整。
5. **同题多模型**：同一条提示词接了好几个模型的，就是作者在做模型对比。
6. **一定要看成图和视频抽帧**，不能只看提示词。提示词写得好不代表成片好。
