## 1. 即梦里的引用写法

即梦 Seedance 的全能参考模式里，上传的素材按顺序编号，提示词里用 `@图片1`、`@视频1`、`@音频1` 引用（以即梦界面上实际显示的素材名为准）。从 TapNow 画布学来的提示词里写的是 `{{Image 1}}`，迁移时统一替换。

上传顺序建议固定：**首帧（如果有）→ 场景 → 人物脸 → 服装 → 道具 → 其他**，然后音频。顺序固定了，提示词模板可以复用。

Seedance 2.5 单次上限：30 张图、10 段视频、10 段音频。素材数量一般不是问题，问题是**每张图的职责有没有写清**。

## 2. 通用规则

- **时长与镜头数**：按这条视频的用途定。
  - **整段要用的段落**（剧情、对白、情绪戏，生成结果基本整段进成片）：镜头数 ≤ 秒数 ÷ 3。15 秒写 4–5 个，30 秒写 8–10 个。
  - **素材池**（产品片、动作戏、蒙太奇，只挑其中 1–3 秒进成片）：可以放宽到镜头数 ≤ 秒数 ÷ 2。15 秒写 6–7 个，20 秒写 8–10 个。镜头多一些，剪辑时可选的就多。
  - 两种都不能更密。实测 15 秒写 15 个镜头，只出来一半。
- **先草稿后正片**：同一条提示词先用低分辨率 / 便宜档跑 2–3 次看构图和走位，满意后再出 1080p。改提示词的成本远低于重跑正片。
- **轴线**：开头就写"画左始终是 A，画右始终是 B，任何切镜都不交换"。
- **声音默认**：无 BGM、无字幕、无旁白，只保留画内声音和写出来的台词。配乐后期统一加，否则每段风格不一。
- **台词逐字写出**，并写语气和声音特征。不写的话模型可能自己编台词，或者随机说外语。
- **严禁项要具体**："禁止第二镜开场就全虚焦"比"不要模糊"有用。

## 3. 完整版模板（9 段式）

适用：多人、有台词、有情绪表演、20–30 秒的段落。来自"最后的问题"和"无人之梦"两个画布，是五个画布里质感最高的写法。

```
# 段落编号｜段落名

【SCENE CONTEXT｜时长、镜头数、剧情概述】
总时长 X 秒，N 个镜头。一段话讲清：在哪里、谁、发生了什么、从什么状态开始、到什么状态结束。

【REFERENCES｜素材职责】
@图片1：场景参考。负责锁定空间结构、尺度、光源位置、曝光、黑位、空气感和整体摄影语言。
        本图的光影优先级高于其他所有素材。
@图片2：A 的人物资产。只锁定身份、脸部骨相、年龄、发型、体型。
        严禁继承这张图的棚拍面光、浅灰背景、清晰锐度和高亮皮肤曝光。
@图片3：A 的服装。锁定款式、颜色、磨损位置。
@图片4：道具 X。锁定尺寸、材质、细节；三视图的白底和标注不进入成片。
@音频1：A 的音色参考。
（每张图写清：只负责什么 / 不负责什么 / 在第几秒使用 / 是不是首帧）

【VISUAL CONTRACT｜最终画面锁定】
一段话描述成片应该长什么样：主光从哪来、人物脸上哪里亮哪里暗、黑位多深、
镜头运动的整体风格（缓慢精确 / 手持不安）、景别分布。

【ENVIRONMENT｜环境如何影响人物和画面】
风、雾、雪、灰尘、光的变化怎么作用在人物的头发、衣服、脸上。

【ACTING｜人物关系、动机、表演】
人物之间是什么关系，这一刻各自在想什么，潜台词是什么。
表演写到可见的身体变化：呼吸、视线、下颌、肩膀、手指。

【VISUAL RULE｜摄影的物理规则】
用光学和物理机制描述关键效果，而不是形容词：
光源位置不随机位变化；焦平面怎么移动；门 / 窗 / 屏幕如何关闭；粒子如何受力。

【SHOT DESIGN｜分镜】
镜头1｜0:00–0:06，6秒。景别、机位、运动方式。画面内容。人物动作。台词（逐字）。
镜头2｜0:06–0:11，5秒。……
（切镜时写清"在什么动作中切"，跨镜动作写明"连续，不重新开始"）

【SOUND DESIGN｜声音】
无 BGM、无字幕、无旁白。列出画内声音和发生时间。台词的语气、音量、声源方位。

【STRICTLY EXCLUDE｜严禁项】
具体列出最担心的错误。
```

## 4. 精简版模板（5 段式）

适用：人物少、动作明确、10–15 秒。

```
# 段落名
真人实拍电影质感（或：风格指令）。一句话概述本段。

## 素材
@图片1 场景，锁定空间和光线，不作为首帧。
@图片2 只锁定 A 的脸和体貌，衣服以 @图片3 为准。
@图片4 道具 X，尺寸……

## 光线与镜头
主光方向、光色；轴线规则；整体运镜风格。

## 时间轴
0–4 秒｜……
4–9 秒｜……
9–15 秒｜……

## 声音
无 BGM、无字幕。画内声音：……台词："……"
```

## 5. 分镜清单版模板

适用：动作戏、追逐、蒙太奇、快节奏。来自 KILL A 画布，写起来快，适合大量出片。

```
镜头1-[运镜方式]，[景别与构图]，[画面内容与动作]，[光线与镜头质感]。
镜头2-……
镜头3-……
镜头4-……

说明：可以生成音效，不要生成音乐，不要生成字幕。
[场景名]参考 @图片1，[场景名]参考 @图片2，[角色名]参考 @图片3 @图片4，
人物材质严格参考人物参考图，[角色名]声音参考 @音频1。
```

范例：
> 镜头1-侧方快速跟拍，橙发女子米娅从画外惊惶奔入电梯厅，疯狂按压电梯按钮，大光圈极浅景深下，顶部的冷冽灯光在黑柔滤镜下为她勾勒出立体的轮廓光。
> 镜头2-特写微推，极浅景深聚焦于米娅颤抖的手指，疯狂且无助地连续按压电梯按钮，按钮的微光在黑柔滤镜下产生朦胧溢出，背景完全虚化。
> 镜头3-高空俯视微摇，俯拍米娅的面部，她焦急地抬头左右张望电梯指示灯，发现毫无反应后，顶光在面部打出立体的明暗阴影，她猛地转过身，冲入旁边的应急安全通道。
> 说明：可以生成音效，不要生成音乐，不要生成字幕。应急通道参考 @图片2，电梯厅参考 @图片1，米娅参考 @图片3 @图片4，米娅声音参考 @音频1。

## 6. 写法要点

### 参考图的职责
最常见的失败是资产图的光线漏进成片：人物资产是灰底棚拍，结果成片里出现一帧灰背景的人脸。每张人物 / 道具资产都加一句：
> 只负责锁定身份和外形。资产图自身的灯光、曝光、背景、锐度和展示式构图全部忽略，正式画面中人物必须处于场景统一的光线逻辑之中。

### 表演：写肌肉，不写情绪词
| 不要写 | 改成 |
|---|---|
| 他开心地笑了 | 两侧嘴角向外上方拉开，颊部上提，下眼睑随之抬高，眼尾收出浅纹，上齿短暂露出 |
| 他很失望 | 最初半秒完全不动，随后一次很轻的眨眼，下颌收紧再松开，慢慢呼出一口气 |
| 他犹豫了 | 嘴唇微开，停半秒，手指停在盔沿，回答短而平静 |
| 他咬了一口很硬的饼干 | 牙齿遇到硬饼干时下颌停一下，腮侧咬肌短暂绷紧，眉间轻收，随后咬下一小角，转用后槽牙慢慢嚼 |

同时写动机和潜台词，模型会据此调整微表情：
> 甲乙仍觉得这是睡前闲谈；A 的表情则逐渐与他们错开。

### 镜头
- 运镜写成真实设备：轨道横移、升降、直线推近、手持、斯坦尼康。写明"启动和停止有轻缓的加速度，不做数字匀速滑动"。
- 镜头质感写具体参数比写"电影感"有效：大光圈浅景深、黑柔滤镜、变形宽银幕眩光、28mm 广角深焦、Helios 旋焦。
- 跨镜动作连续：`打斗动作跨镜连续，不重新开始翻滚` / `动作在摄影机停下后继续，不重做插铲`。

### 转场
把转场设计进提示词，而不是指望后期：
- **遮挡转场**：渡鸦穿过一团横向飘动的浓烟，浓烟遮满画面，穿出时已是梦境。写明"飞行方向和镜头速度在转场前后连续"。
- **运动匹配硬切**：第 11 秒在向右横移中直接切到另一个场景，新画面里镜头仍向右横移，再逐渐减速停住。写明"不把荒地连续变形成掩体，不把奔跑姿势逐帧变成蹲姿"。
- **视觉母题串联**：蝴蝶和花瓣从图 1 飞向图 2，沿途建筑开花（首尾帧模式）。

### 物理机制代替特效词
| 想要的效果 | 写法 |
|---|---|
| 拉焦虚化 | 摄影机位置不变，仅连续改变对焦距离，将焦平面移离火星所在区域。不能用火星飘远、变暗或拖影代替拉焦 |
| 空间门出现 | 一小块空气先出现轻微折射偏移，背景直线经过该区域时像引力透镜一样弯曲，随后微粒沿竖向矩形聚集成几乎透明的膜 |
| 窗口关闭 | 可视区域从四周沿建筑轴线同步向中心内缩，环境反光同步衰减；不出现 HUD、图标、扫描线或显示器关机动画 |
| 剧烈的太阳表面 | 从第一帧开始整个可见表面持续大幅运动……不要生成静止太阳贴图，不要仅通过曝光变化模拟活动 |

### 污损与状态的连续
> A 的袖口、衣襟和膝部逐渐沾上湿泥……这些战损随着接触逐步形成，后续镜头保留其位置和程度。

### 虚构语言台词
架空世界可以发明一门语言，写出每句台词的音节，并说明重音规则（例：维岚语，固定音节，首音节重音）。好处是不会念错中文，同时保住架空感。

## 7. 范例片段

### 完整版：夜间战壕对话（30 秒，Seedance 2.5，定稿）
> **素材**：@图片2 只锁定 A 的脸、短发和体貌。A 穿 @图片3 的深橄榄绿前线军服，保留立领、围巾、腰带弹药袋、绑腿和旧皮靴。裤腿、靴面、袖口有干湿交错的泥雪……
> @图片1 只锁定地面以下的战壕环境。**场景整体极暗，唯一照明是图中的那盏提灯**：灯旁一小片木板和近处脸部可见，离灯稍远的木墙、壕口和人物轮廓迅速沉入黑暗。提灯始终在 A 右侧低处，随 A 靠近才逐渐照出他的面部；远处炮火只以声音存在，不为画面增加照明。
>
> **时间轴（节选）**：21–29 秒｜切 A 正面，抱盔入睡。乙尾音落下，直接切到 A 胸口以上的正面近景……A 的背逐渐贴实木墙，最初一次眨眼仍带着听完玩笑后的清醒；接着下颌和肩膀一点点松开，呼吸由浅快变得均匀，眼皮缓慢合上……**双眼完全合上后，镜头再停半秒**，以 A 抱着钢盔睡去的画面结束。

### 完整版：观测舱（30 秒，宽银幕科幻）
> **VISUAL CONTRACT（节选）**：男人绝大部分时间只通过顶部光线、斜侧逆光和侧后方边缘光被勾勒出来，脸部即使进入侧面镜头，也只允许额头、鼻梁边缘、颧骨、发丝、下颌和服装折面出现局部亮部，其余五官沉入阴影……观测窗外的宇宙几乎完全黑暗，不能做成漂亮银河或者星云景观。

### 精简短镜头：烽火台火星微距（6 秒，2 个镜头）
> 镜头2｜2—6秒：固定机位，超级微距大特写空镜……前 1.5 秒保持准确聚焦，数颗经过焦内的火星清晰锐利；随后 1.5 秒连续、缓慢拉焦，清晰火星的边缘逐渐变软；最后 1 秒达到完全虚焦，所有火星均成为柔软光斑，新进入画面的火星也不再清晰。火星持续以正常速度上升，摄影机不移动、不变焦、不减速。
> 严禁：第二镜开场全虚；把清晰火星画成纯圆形光球；用过曝光晕或火星熄灭代替脱焦；结尾重新聚焦；慢动作。
