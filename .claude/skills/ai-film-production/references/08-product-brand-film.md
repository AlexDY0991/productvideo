# 产品与品牌片

适用：汽车、摩托、飞行器、无人机、硬件设备等**以产品为主角**的品牌片、广告、发布片。

主要依据是 Higgsfield《RACER 18》：一部以摩托为主角的 AI 片子，207 条生成记录，成片 297 秒。我拆了它的全部提示词，也逐镜头拆了成片。

## 1. 产品片和剧情片的区别

| | 剧情片 | 产品片 |
|---|---|---|
| 主角 | 人物 | 产品（人物是陪衬和情绪来源） |
| 最怕什么 | 脸不一致 | **产品外形画错**（零件数量、比例、涂装、logo 位置） |
| 镜头长度 | 可以长 | 短：成片里一半的镜头不到 2 秒 |
| 动作 | 表演为主 | 运动为主：速度、姿态、光线扫过表面 |
| 风险 | 剧情逻辑 | 品牌合规：参数、宣传口径、第三方品牌、安全形象 |

## 2. 七步制作方案

《RACER 18》的做法，按顺序：

1. **项目简报**：一句话梗概、主线、视觉语言，章节怎么分（它按国家分章节，每章各有视觉风格）。
2. **资产库**：产品六视图 → 产品细节 → 人物 × 场景服装 → 场景。9 天建了 89 个命名资产。
3. **镜头类型库**：先列出全片要用到的产品镜头类型（见第 4 节），每种至少准备一条成功的提示词。
4. **生成长素材**：每条 10–20 秒，镜头数 ≤ 秒数 ÷ 2（15 秒 6–7 个，20 秒 8–10 个），把它当成"素材池"，而不是成片。
5. **剪辑挑秒**：从每条素材里挑最好的 1–3 秒。成片 107 个镜头来自 146 条生成。
6. **媒体层和片尾字卡**：手机屏幕、社交媒体、直播画面穿插；片尾字卡后期合成。
7. **声音**：生成时带原生音效（引擎、风、人群），配乐后期统一加。

## 3. 产品资产

### 3.1 主资产：带标注的写实六视图
左侧、右侧、正面、背面、顶视、前 3/4，每格下方写视图名。

来源按可靠程度排序：
1. **3D 模型直接渲染**：最准。还可以用来做 Layout（见 `02-scene-and-keyframe.md`），机位和构图完全可控。
2. **工程图或涂装图 + 实拍照片**：用 gpt-image-2 或 Nano Banana Pro 生成写实六视图。工程图负责比例和结构，照片负责材质。
   > 根据@图片1 的六视图涂装图和@图片2 的实拍照片，生成这个产品的写实六视图展示图：左侧、右侧、正面、背面、顶视、前 3/4，每格下方用小字标注视图名。严格保持图1的结构比例、零件数量和涂装位置，材质参考图2（碳纤维、哑光金属、白色烤漆）。中性灰无缝背景，均匀柔光，无阴影干扰，无其他文字。
3. **只有实拍照片**：先拍全角度，再让模型整理成六视图。

### 3.2 细节资产
每个会被特写的部位单独做一张：驾驶舱、动力单元、关键结构件、灯、材质面、logo 所在位置。特写镜头引用细节资产，不引用整体六视图，否则细节会被模型"补"错。

### 3.3 状态和变体
- **涂装变体**：每套配色各做一套六视图，命名区分（`产品-白`、`产品-橙`）。
- **状态**：静止 / 运行（轮子转、桨叶转）、折叠 / 展开、停放 / 行驶或飞行。会出现的状态都要有参考。

### 3.4 人物
驾驶者和使用者按"人物 × 场景服装"做资产（见 `01-setting-and-assets.md`）。产品片里的人物负责情绪：驾驶时的专注、落地后的笑、旁观者的惊叹。

## 4. 产品镜头类型库

从《RACER 18》成片里归纳出来的产品镜头，每种标了它在成片里通常停留多久：

| 类型 | 画面 | 在成片里的时长 |
|---|---|---|
| 迎面英雄镜头 | 低机位前 3/4，产品朝镜头冲来再掠过 | 2–5 秒，开场常用 |
| 侧向跟拍 | 机位与产品平行高速移动，背景强烈拉丝 | 1–3 秒 |
| 航拍俯视跟随 | 正上方或高空斜俯，产品在大环境里运动 | 2–4 秒 |
| 驾驶者视角 | 从驾驶位往前看，手和操控部件入画 | 1–2 秒 |
| 微距细节 | 轮子、动力单元、材质、灯，浅景深 | 0.5–1.5 秒 |
| 人物特写 + 产品前景 | 驾驶者的脸，前景是产品的局部 | 1–2 秒 |
| 环境中的产品 | 产品在标志性场景里（海、雪山、城市夜景） | 2–4 秒 |
| 动作高潮 | 腾空、急转、起飞落地 | **0.5–1 秒**，物理不可信的部分用快剪藏住 |
| 旁观者反应 | 人群、孩子、路人的惊叹 | 1–2 秒 |

## 5. 产品镜头的提示词写法

### 5.1 产品锁定段（每条都写）
> 产品：@图片2 是本片的唯一主角产品。严格保持它的外形、比例、结构、零件数量、颜色、涂装位置和材质。不得替换成其他型号或其他交通工具；画面里如果出现其他同类产品，必须在外形和颜色上明显不同，不得复制主角产品的设计。

《RACER 18》原文的写法：
> Preserve its exact established identity, proportions, frame geometry, colors, and mechanical appearance… Never replace it with another vehicle.
> Each co-rider's motorcycle must be visually distinct. DO NOT copy the hero bike's design onto the co-riders' motorcycles.

### 5.2 参考图只锁身份，不锁构图
> 参考图只用来锁定产品和人物的外观，不要照搬参考图的构图、机位、灯光和背景，按本条提示词重新设计镜头。

（原文：DO NOT COPY THE UPLOADED IMAGE FRAME-BY-FRAME.）

### 5.3 运动和物理用清单写
不写"速度很快"，而是列出看得见的物理反应：
- 车类：悬挂压缩回弹、轮胎变形、轮子转速和地面拉丝匹配、车身反光随运动移动、扬起的尘土 / 水花 / 雪。
- 飞行器：桨叶高速旋转呈半透明模糊圆盘；下洗气流压倒草地、吹皱水面、卷起尘土；起飞时离地有轻微晃动后稳定；飞行姿态平稳，转向时机身轻微倾斜。
- 速度感：背景运动模糊、视差、光源拉成线条、机位轻微震动。**主体保持清晰，背景模糊。**

### 5.4 动作写简单
起步、行驶或飞行、掠过、转弯、停下或降落。腾空、翻滚、碰撞这类动作，物理基本不可信。确实需要时，在提示词里写清楚，成片里只用 0.5–1 秒。

### 5.5 严禁项写具体
《RACER 18》撞车镜头的严禁项可以照着写：
> 不要轮胎火花，不要夸张的好莱坞火球，不要卡通火焰，不要复制出多个主角，不要不真实的布娃娃式摔倒，不要全程慢动作，不要模糊的车身，不要错误的品牌标识。

### 5.6 即梦里的产品镜头模板

```
# 段落名｜X 秒
真人实拍商业广告质感，[画幅]。一句话概述本段。

@图片2 产品细节：[部位]，特写镜头以此为准。
@图片3 驾驶者：只锁定脸和体型；服装以 @图片4 为准。
@图片5 场景：锁定环境和光线，不作为首帧。

## 镜头（每个 2–4 秒，生成后剪辑挑选）
```

## 6. 生成策略：长素材 + 多机位

**一条生成 = 一个素材池。** 每条写 10–20 秒，镜头数 ≤ 秒数 ÷ 2，预期只有其中 1–3 秒会进成片。不要指望一条生成就是成片。

这条比剧情片的"镜头数 ≤ 秒数 ÷ 3"宽松，原因是用途不同：剧情段落要整段能用，镜头必须写得疏；素材池只要有几秒好用，镜头可以写得密一些。但不能再密，15 秒写 15 个镜头会被压缩丢掉一半。

一部片子里两种都会有：产品和动作镜头按素材池写，人物的情绪戏、对白戏按剧情段落写。

**多机位写法**：同一个动作用 A / B / C 三个机位各拍一遍，剪辑时就有得选。《RACER 18》的汉堡广告就是这样写的：
> SHOT 01 — HERO FOOD MACRO
> Camera A — 85mm macro: Extreme close-up…
> Camera B — 45° food angle: Slow cinematic slider movement…
> Camera C — Low-angle macro: Camera sits almost at table level…

产品片可以照搬：同一次掠过，A 机位低角度迎面、B 机位侧向跟拍、C 机位航拍俯视。

**主角产品镜头多跑几次。** 产品外形是硬指标，同一条提示词跑 2–3 次，挑外形最准的那条。

## 7. 剪辑节奏：成片怎么用素材

《RACER 18》成片的数据：297 秒、107 个镜头，平均每个镜头 2.8 秒，一半的镜头不到 1.8 秒。最长的 27 秒（一段带对白的戏）。

规律：
- **动作和产品镜头快切**（0.5–2 秒），情绪和对白镜头才给长时间。
- **AI 的瑕疵用快剪藏住**：腾空、碰撞这类物理不可信的画面只留不到 1 秒。
- **开场 30 秒密度最高**：片名 → 隧道英雄镜头 → 航拍 → 卡车飞跃 → 手机里的围观反应，连续 15 个镜头。
- **每段动作后接一个人物反应**：孩子的脸、人群、驾驶者的特写。产品负责视觉冲击，人物负责情绪。

## 8. 媒体层和片尾

- **媒体层**：手机屏幕上的短视频、社交媒体点赞、直播和新闻画面、多屏监控墙。让片子有"正在被全世界关注"的当代感。屏幕里的内容可以是之前生成的镜头，后期合成进去更可控。
- **片尾字卡**：AI 能生成干净的标题文字（"RACER 18 / COMING SOON" 都写对了），但**品牌 logo 和产品名一律后期合成**，不让 AI 画。

## 9. 品牌安全

- **参数和宣传口径**：画面里暗示的性能（速度、续航、载重、使用场景）要和官方口径一致，不能夸大。有品牌口径文档就先读。
- **不出现第三方品牌**：服装、道具、环境里不要有真实品牌的 logo 和标志性花纹。《RACER 18》里的奔驰、LV、古驰在商业项目里都是风险。
- **安全形象**：交通工具类产品要表现安全、合规的使用方式。不画危险驾驶、不画在人群上方飞、不画违规场景，除非品牌方明确同意。
- **logo 和产品名**：后期合成。

## 10. 产品镜头质检清单

每条生成都检查：
- [ ] 零件数量对吗？（轮子、机臂、桨叶、灯）
- [ ] 比例对吗？（产品和人的大小关系）
- [ ] 涂装颜色和位置对吗？
- [ ] logo 区域是空的，或者形状对、方便后期替换？
- [ ] 产品和地面的接触、阴影合理吗？
- [ ] 运动部件的状态对吗？（行驶时轮子在转、飞行时桨叶在转）
- [ ] 速度感来自背景模糊，主体是清晰的？
- [ ] 画面里有没有第三方品牌？
- [ ] 动作有没有不安全或不合规的暗示？
