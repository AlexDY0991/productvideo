# 检查清单

## 1. 生成视频前

- [ ] 视觉规范卡里的固定说法，在这条提示词里原样出现了吗？
- [ ] 画面里出现的每个人、每件衣服、每个道具都有对应资产吗？
- [ ] 每张参考图都写了"只负责什么 / 不继承什么"？
- [ ] 人物资产写了"不继承棚拍光、背景和锐度"？
- [ ] 镜头数符合用途？整段要用的段落 ≤ 秒数 ÷ 3；素材池 ≤ 秒数 ÷ 2
- [ ] 轴线写清楚了（谁在画左、谁在画右）？
- [ ] 台词逐字写出？语气和声源方位写了？
- [ ] 写了"无 BGM、无字幕"？
- [ ] 提示词里有没有钟表时间、错别字、片名拼写错误？
- [ ] 需要衔接的段落，首帧 / 尾帧准备好了？

## 2. 连续性（跨镜头、跨段落）

- [ ] 人物的脸、发型在各镜头里一致
- [ ] 服装、徽章位置一致
- [ ] 伤痕、泥污、血迹的位置和程度只增不减
- [ ] 道具的位置和状态（打开 / 关闭、拿在哪只手）连续
- [ ] 画面左右关系没有互换
- [ ] 光源方向和光色在同一场景内不变
- [ ] 天气、时间（雪量、天色）一致

## 3. 翻车清单（都是真实发生过的）

| 现象 | 原因 | 预防 |
|---|---|---|
| 画面里印出"08:30 AM" | 提示词写了"时间是早上 08:30" | 用光线描述代替钟表时间："清晨低角度斜射阳光" |
| 海报片名印成 "LKill A" | 提示词里片名拼错 | 所有要出现在画面里的文字都要校对 |
| 成片中出现灰色背景的人脸 | 资产图的棚拍光漏进来 | 写"资产图的灯光、背景、锐度全部忽略" |
| 15 秒只出了一半镜头 | 写了 15 个镜头 | 整段要用 ≤ 秒数 ÷ 3；素材池 ≤ 秒数 ÷ 2 |
| 架空国家的士兵戴德军钢盔 | 钢盔没做资产 | 出镜的东西都做资产 |
| 猫在视频中途消失、人物被裁掉头 | 首帧构图太紧、主体没写清 | 写明"橘猫全程留在画面左下"；首帧构图留余量 |
| 二维动画像三维插帧 | 视频模型默认补满帧 | 后期抽成一拍二 / 一拍三 |
| 车身几何变形 | Sora 对硬表面不稳 | 车、建筑、产品用 Seedance / Veo |
| 自动加雨、加闪光 | Wan 自由发挥 | 换模型，或写进严禁项 |
| 光速穿梭等廉价特效 | 写了"极致""震撼"之类的词 | 用物理机制描述，写"不使用数字特效" |
| 三视图的白底或尺寸标注进入成片 | 没声明 | 写"三视图背景、标注、示范手不进入成片" |
| 夜戏平光、像白天调暗 | 没写唯一光源 | 写"唯一照明是 X，离光源稍远处迅速沉入黑暗" |
| "电影感"写了五遍，效果平庸 | 形容词没有信息量 | 换成具体的光源、镜头、运动描述 |
| 摩托飞跃时在半空悬停好几帧 | 特技动作的物理模型不可信 | 产品动作写简单：起步、行驶、掠过、停下 |
| 产品外形细节全丢 | 产品在画面里太小 | 展示细节的镜头让产品占画面足够大 |
| 画面里出现奔驰、LV、古驰等真实品牌 | 服装和道具描述里写了品牌，或参考图带了 logo | 服装用"无 logo"描述；商业项目避免真实第三方品牌 |

## 4. 交付前

- [ ] 所有镜头用同一个主力视频模型（或已确认不同模型的风格能统一）
- [ ] 配乐、环境音在后期统一处理
- [ ] 二维动画已抽帧
- [ ] 涉及真人肖像（明星、真实人物）已确认授权
- [ ] 涉及品牌、商标的画面已确认可以使用
