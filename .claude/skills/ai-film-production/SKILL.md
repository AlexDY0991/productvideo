# AI 影视短片制作

这套方法来自对 5 个高质量 TapNow 画布和 1 个 Higgsfield 项目的拆解（写实战争片、宽银幕科幻、风格化 3D 动画、动画 TVC、城市宣传片、摩托赛车电影），把它们反复验证有效的做法整理成可执行的流程。默认平台分工是 **Lovart 出图、即梦 Seedance 出视频**；换平台时流程不变，只换模型和引用写法。

## 核心判断：质感从哪里来

五个画布的质感差距，几乎都能归结为下面四件事做没做到。写任何提示词之前先对照一遍：

1. **构图和光线由人控制，不交给模型猜。** 最好的两个画布，一个用场景参考图锁定光影，一个用 3D 灰模锁定机位；最差的那个只写"电影感、导演思维"。
2. **每张参考图只负责一件事。** 人物资产图只锁身份，场景图锁光影和空间，服装图锁服装。写明"只锁定什么、不要继承什么"，尤其不要继承资产图的棚拍光。
3. **用具体的物理描述代替形容词。** 写光源在哪、焦平面怎么移、肌肉怎么动、镜头怎么走。"电影质感"重复五遍几乎没有作用。
4. **出镜的东西都要有资产。** 没做资产的东西，模型会用真实世界的默认样子补上（架空国家的士兵戴上了德军钢盔）。

## 工作流程

按顺序推进。每一步都说明了要读哪个参考文件，需要时再读，不必一次读完。

### 第 0 步：判断片型

主流程（第 1–6 步）所有片型都走。片型决定的是**要不要加读产品片模块**，以及镜头写多密、剪多快：

| 片型 | 判断依据 | 怎么做 |
|---|---|---|
| 剧情片 / 艺术短片 / 品牌概念片 | 主角是人、故事或文化意象，没有需要精确还原的具体产品 | 只走主流程。段落要整段能用，节奏可以慢 |
| 产品片 | 某个具体产品是主角，外形必须准确（车、飞行器、硬件） | 主流程 + `references/08-product-brand-film.md`。产品镜头按素材池写，剪辑快切 |
| 混合 | 有产品，也有人物情绪线（大多数品牌片） | 产品镜头按产品片模块写，人物的情绪戏和对白戏按主流程写 |

一般从用户的需求和素材就能判断（比如给了产品工程图，就是产品片），**能判断就直接判断，并在第一次回复里说明按哪种片型做**。只有分不清时才问用户一句："这部片子的主角是产品本身，还是人和故事？"

### 第 1 步：设定与视觉规范

先产出一张"视觉规范卡"：时代、地点、色调、光线基调、画幅（16:9 / 21:9）、材质关键词、阵营或品牌的固定配色。规范卡里的每个关键说法，之后在所有提示词里**原样重复**，这是跨几十个镜头保持统一的最便宜的办法。

如果是风格化作品，先花一轮专门探索风格，选定后把它压缩成一句"材质指令"（例如"冷陶瓷油光质感"），后面所有资产都用这句话改。

→ 模板见 `references/01-setting-and-assets.md`

### 第 2 步：资产库

逐一做出：
- **人物资产板**：固定版式（上方正脸 + 斜侧脸近景，下方三张去头全身图），加真实感前缀和"制造不对称"的描述。
- **服装资产**：和脸分开做。视频里"脸看人物图，衣服看服装图"。换装多的项目，直接把"角色 × 服装"组合做成独立资产。
- **道具三视图**：写明尺寸和材质细节。任何会在画面里被拿起、被看清的东西都要做。车、飞行器这类大型产品做带标注的六视图。
- **真实空间**：品牌片里要出现的真实店面、酒店、建筑，用实景照片锁定空间身份，再按规范卡的光线重新生成，照片本身不直接进视频。
- **复杂主体的形态总表**：一个主体有多种形态时（比如会变形的 AI 生命体），合成一张总表，视频里引用这一张。
- **音色**：每个有台词的角色准备一段音频作为音色锚点，所有视频复用。

资产命名用编号：`A01_人物名_三视图`、`PR03_烟盒_三视图`、`SC_07_场景名`。传到即梦时文件名就是引用依据，乱命名后面会引用错。

→ 模板见 `references/01-setting-and-assets.md`

### 第 3 步：空镜与关键帧

- **空镜不放人**（`--no people, text`），构图时预留表演空间（"可容纳两人扭打的空地"）。空镜是视频的光影和空间锚点。
- **按精度需求选构图控制方式**：文字描述 < 画框标注 < 3D 灰模 Layout。广告和高要求镜头用 Layout。
- **四宫格选镜头**：先出四个角度，挑中再"单独生成出来"，比一张张试便宜。
- **局部精修一次只改一处**："X 去掉，其他什么都不变"。一个关键帧改到 v010 很正常。
- **首帧 / 尾帧**：段落之间需要无缝衔接时，用上一段的尾帧做下一段的首帧。

→ 模板和精修话术见 `references/02-scene-and-keyframe.md`

### 第 4 步：视频提示词（即梦 Seedance）

根据镜头复杂度选模板：

| 情况 | 用哪种 |
|---|---|
| 多人、有台词、有表演、20–30 秒段落 | 完整版（9 段式） |
| 动作清楚、人物少、10–15 秒 | 精简版（5 段式） |
| 快节奏动作戏、蒙太奇 | 分镜清单版 |

无论哪种，都要满足：
- **镜头数按用途定**：整段要用的段落 ≤ 秒数 ÷ 3（15 秒 4–5 个）；素材池（产品、动作、蒙太奇，只挑 1–3 秒用）≤ 秒数 ÷ 2（15 秒 6–7 个）。再密会被压缩丢镜头。
- **每张参考图写明职责和使用时段**，并声明"不继承资产图的灯光、背景、锐度"。
- **轴线固定**："画左始终是 A，画右始终是 B，不交换"。
- **表演写到肌肉层面**：不写"他笑了"，写"颊部上提，下眼睑抬高，眼尾出现浅纹"。
- **声音单独一段**：默认无 BGM、无字幕，只写画内声音；台词逐字写出。

→ 三套模板、即梦引用写法、范例见 `references/03-video-prompt.md`

### 第 5 步：声音

环境音按时间点写事件；配乐写清主乐器、节奏型和**要排除的套路**；配音可以先单独生成纯人声，再作为音频参考。

→ 模板见 `references/04-sound.md`

### 第 6 步：检查与迭代

每生成一版，对照连续性清单和翻车清单检查，再决定改提示词还是改参考图。命名里标 ✅ / ❌ / tryN，保留迭代记录。

→ `references/06-checklists.md`

## 产品与品牌片

第 0 步判断为产品片或混合片时加读。它是主流程的补充，不替代主流程：产品外形准确是硬指标，产品镜头的每条生成只是素材池，靠剪辑挑出最好的 1–3 秒；成片节奏快，一半的镜头不到 2 秒。七步方案、产品资产、镜头类型库、提示词模板、品牌安全和质检清单 → `references/08-product-brand-film.md`

## 平台与模型

默认分工：**Lovart 出图（Midjourney、Nano Banana Pro、gpt-image-2、Seedream 都有），即梦出视频（Seedance 2.5）**。即梦的 Seedance 2.5 单次最多 30 张图、10 段视频、10 段音频作参考，素材数量不是瓶颈。

按任务选模型、各模型的已知毛病 → `references/05-models-and-platforms.md`

## 输出约定

帮用户做项目时，按阶段交付，不要一次倒出全部内容：
1. 先给视觉规范卡和资产清单，让用户确认方向。
2. 再逐个给资产提示词（标明用哪个模型、什么比例）。
3. 资产确定后，再写分镜表和视频提示词。

每条提示词前标注：**平台 / 模型 / 比例 / 时长 / 需要上传的参考素材（按顺序）**。用户要能直接复制粘贴。

提示词默认用中文写；Midjourney 的空镜用英文写（它对英文理解更好），句尾加 `--ar` 和 `--no`。

## 学习别人的画布

用户给出 TapNow 分享链接时，可以用 `scripts/` 里的脚本抓取完整数据（提示词、参数、引用关系、成图），分析方法见 `references/07-case-studies.md` 末尾。五个已拆解案例的要点也在这个文件里，需要具体例句时去查。
