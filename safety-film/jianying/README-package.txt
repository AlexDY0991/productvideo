酷飞 Dream Pro · 安全 —— 剪映工程（{DRAFT}）
================================================

一、安装剪映草稿（Windows）

1. 把整个文件夹解压到电脑上一个固定位置（例如 D:\CoolFly\）。
   之后不要再移动这个文件夹；如果移动了，重新做一次第 2 步。
2. 先关闭剪映，然后双击 install-draft.bat。
   - 窗口里会显示检测到的剪映草稿位置，直接按回车即可；
   - 如果你在剪映「全局设置 → 草稿位置」里改过位置，把那个路径粘贴进去再回车。
3. 打开剪映，在草稿列表里找到「{DRAFT}」并打开。

二、草稿里的轨道（从下到上）

  三维画面    每个场景一段视频，不带任何文字。可剪短、调速、调顺序、加转场。
  标注层      透明背景的标注框和右侧视野标尺，跟三维画面一一对齐。可整条关掉或挪时间。
  角标Logo    左上角 CoolFly 标志（整幅透明图片，位置已对好）。
  片尾黑底 / 片尾Logo / 片尾标语 / 片尾网址    片尾，淡入。
  标题 / 标题英文    左下角大标题和英文副行，剪映文字，可直接改字。
  三层1–3     开场的“01 冗余 / 02 主动安全 / 03 被动安全”。
  角标文字    右上角 DREAM PRO · SAFETY。
  字幕        由 media/subtitles/subtitles-zh.srt 导入，剪映文字，可直接改。
  配音        每句一段，可单独替换（例如换成火山引擎配音）。

注意：三维画面里的镜头、模型和动画是渲染出来的，在剪映里改不了；
标注框跟着三维部件走，所以也只能整条开关或挪时间，不能改字。

三、素材包（media 文件夹，也可以拖进 Premiere、达芬奇等其他软件）

  media/plate       三维画面，按场景分段（mp4）
  media/overlay     透明标注层，按场景分段（ProRes 4444 .mov，带透明通道）
  media/voice       分句配音（wav）
  media/subtitles   中文字幕（srt）
  media/images      角标 Logo、片尾 Logo、片尾黑底（png，整幅 1920×1080）
  media/reference   对照用的完整成片（有的话）

四、这一版小样需要你帮忙确认

  1. 草稿能不能打开，有没有提示“素材丢失”。
  2. 标注层是不是透明的（能看到下面的三维画面）。
  3. 字幕、标题的位置和大小合不合适，可以对照 media/reference 里的成片。
  4. 透明格式测试：把 media/alpha-test 里的四个文件（A/B/C/D）分别拖到时间线最上面，
     看哪几个背景是透明的，告诉我字母就行。
