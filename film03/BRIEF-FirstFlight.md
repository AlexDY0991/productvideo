# film03「FIRST FLIGHT」· 创意简报 v1（2026-10-30）

## 1. 为什么是这个方向

### 和 film02 的区别
| | film02（用户自己剪的版本） | film03 |
|---|---|---|
| 回答的问题 | **为什么要拥有它：** 它让家庭生活更好 | **我能不能飞：** 第一次飞的人也能，而且感觉棒极了 |
| 主角 | 父亲，有家庭 | 30 多岁的女性，独自一人 |
| 场景 | 海边牧场、海岸 | 莫哈韦沙漠的干湖床：白色地面、远山、日出 |
| 声音 | 第一人称旁白 | 没有旁白，只有两句现场对白 |
| 视觉 | 多机位剪辑 | 飞行段用一镜到底和 FPV 运镜 |

### 品牌角度
CoolFly 自己的元际片用过 "This time, it really flies"。品牌要建立的认知是：**真实可飞，而且是给普通人飞的**。film02 讲生活方式，film03 讲"人人可飞"的体验，两条片互补，合起来是一套完整的品牌叙事。

### 受众角度
- 美国的潜在用户大多是有钱、爱冒险的早期尝鲜者：玩游艇、越野摩托、私人飞行的人，以及牧场主和科技爱好者。
- 他们最大的心理门槛不是"想不想要"，而是 **"我能不能飞？"**。
- 用第一次飞的人做主角，正好回应这个门槛：她紧张，观众也紧张；她笑出声，观众就想去试。
- "第一次"本身也接上了美国人对拿到第一张驾照的集体记忆：那是自由的开始。

## 2. 一句话

> 每个人都记得自己的第一次。这是她第一次飞。

片中字幕（暂定，不是 slogan）：开场 "Everyone remembers their first."。

## 3. 连贯性设定（所有分镜和提示词都必须遵守）

| 项 | 设定 |
|---|---|
| 地点 | 莫哈韦沙漠的干湖床（类似 El Mirage）：龟裂的白色湖床、远处一圈褐紫色山脉、地面没有任何植物和建筑 |
| 时间 | 日出前 → 日出（太阳在 12 秒的鼓点上升出地平线）→ 日出后 20 分钟。全片都是低角度暖光 |
| 太阳方位 | 去程时太阳在画面**左后方**，飞行器的影子投向**右前方** |
| 飞行方向 | 去程**从左往右**，回程**从右往左**。任何一个镜头都不能违反 |
| 高度 | 起飞后贴地 1–5 米，最高约 20 米，不进云，没有鸟 |
| 起降点 | 湖床上一块深灰色方形起降垫。Dream 停在垫子中央，机头朝右 |
| 教练的位置 | 白色皮卡加一顶小遮阳棚，在起降垫**左侧约 60 米**处。起飞和降落时，所有人都在 40 米以外；桨停了才走近 |
| 主角 Maya | 34 岁，美国人，深金色及肩发、低马尾、雀斑。橄榄绿飞行夹克、里面灰色连帽衫、黑裤、棕色短靴。白色头盔配彩虹色面罩和耳机。戴头盔前后发型一致 |
| 教练 Ray | 50 多岁，灰白胡子，旧棒球帽，牛仔夹克，手拿对讲机。全片不靠近飞行器，直到最后 |
| 飞行器 | Dream 白色款，机身有 CoolFly 字样，黑色防滚架，4 根机臂、每根上下两个电机、共 8 个螺旋桨。以 4 张白底参考图为准 |
