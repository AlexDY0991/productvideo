# Dream Pro 卖点片｜完整制作流程 + 第一批提示词

## 平台分工

| 环节 | 用什么 | 谁来做 |
|---|---|---|
| 结构参考渲染、技术可视化（CG 章节） | 3D 模型（glb）直接渲染，加代码做的信息图动画 | 我 |
| 所有静帧：产品资产、人物、场景、关键帧 | **Lovart**（gpt-image-2、Nano Banana Pro、Midjourney、Seedream） | 你生成，我写提示词、做质检 |
| 所有视频镜头 | **即梦 Seedance 2.5** | 你生成，我写提示词、做质检 |
| 剪辑、字幕卡、logo、配乐、9:16 竖版 | 剪映、Premiere 或达芬奇 | 你或剪辑师，我出剪辑表 |

一句话：**静帧都在 Lovart 做，视频都在即梦做，结构准确性靠 3D 模型兜底。**

## 七个阶段

每个阶段过了质检再进下一阶段。命名一律用编号，传到即梦时文件名就是引用依据。

### 阶段 1｜产品资产（Lovart）← 现在在这一步
| 编号 | 内容 | 模型 | 输入 |
|---|---|---|---|
| P01 | 写实六视图（主资产） | gpt-image-2 为主，Nano Banana Pro 对照 | P00 结构渲染 + 官方展开渲染 |
| P02–P05 | 细节：座舱、电机和共轴桨、伞舱盒和雷达、机头灯带 | Nano Banana Pro | P01 + 局部渲染 |
| P06 | 折叠状态（放在拖车上） | Nano Banana Pro | 官方折叠渲染 + P01 |
| P07 | 待飞状态（桨转成半透明桨盘） | Nano Banana Pro | P01 |

**P01 的做法：不让 AI 一次画六个视图，而是一个视图一个视图地"写实化"。** 每次给它一张结构渲染（只管形状）加一张官方渲染（只管材质），让它保持形状不变、只换成真实材质。复杂结构这样做最不容易走样。六张都出好后，由我拼成带标注的六视图。

### 阶段 2｜人物、服装和场景（Lovart）
- A01 飞行员资产板（Nano Banana Pro）：上方正脸和斜侧脸，下方三张不带头的全身图。
- C01 飞行装备、C02 地勤马甲便装（Nano Banana Pro，马甲参考官方图）。
- SC01–SC04 场景空镜（Midjourney，英文提示词，`--no people, text`）。
- SC05 纯黑技术摄影棚（Seedream 或 Midjourney）。

### 阶段 3｜镜头类型试跑（即梦）
正式分镜之前，先用 3–5 条短视频把关键镜头各跑通一次：停放的英雄镜头、起飞、侧向跟拍、掠过海面、驾驶视角。找到能稳定保持外形的写法。

### 阶段 4｜分镜表和关键帧（我写分镜，你在 Lovart 出图）
- 我写约 25 个镜头的分镜表：每个镜头标明章节、时长、类型、来源（AI 还是 3D）。
- 重要镜头先出四宫格选机位，选中后单独精修。
- 局部精修一次只改一处。

### 阶段 5｜视频生成（即梦 Seedance 2.5）
- 每条 10–15 秒，当素材池用，最后只取 1–3 秒。镜头数不超过秒数 ÷ 2。
- 产品主镜头同一条跑 2–3 次，挑外形最准的。
- 预计 12–15 条生成。

### 阶段 6｜3D 技术可视化（我来做）
- CG01 折叠和展开：**直接用公司的 c03 动画**，它比我渲染的质量高，或者问公司要无标注的版本。
- CG02 爆炸图、CG03 NA80 双余度、CG04 雷达范围、伞舱和双电池：我用 glb 渲染，加代码做的信息图动画，配色是黑底、冷白加品牌橙。
- 如果公司还有 NA80、伞舱的官方动画，优先用官方的。

### 阶段 7｜剪辑和交付
- 我出剪辑表：每个镜头取哪条生成的哪几秒。
- 字幕卡、logo、马甲和机身上的 logo 都后期合成或替换。
- 交付 16:9 主版 60 秒，加 9:16 竖版，再出 15 秒和 6 秒短版。

## 第一批提示词：P01 写实六视图

**先做前 3/4 视图试一张**。它是最重要的英雄角度，确认效果后再做其余五张。

### P01-a 前 3/4 视图

- **平台 / 模型**：Lovart / gpt-image-2（同一条再用 Nano Banana Pro 跑一次做对照）
- **比例**：16:9
- **上传顺序**：
  1. 图片1 = `coolfly/3d_renders/V_front34_黑架.png`（结构）
  2. 图片2 = `coolfly/refs/REF_DreamPro_官方渲染_展开.png`（材质和配色）

```
把图片1这张 3D 结构渲染图，重新渲染成一张写实的产品摄影图。

结构完全以图片1为准，不改变任何形状、比例、零件数量和机位角度：外露的黑色管状防滚架及其斜撑走向、前后两组横向伸出的机臂（共4根）、每根机臂末端1台电机、每台电机上下共轴各1副两叶桨（全机共8副桨）、防滚架顶部后方的方形伞舱盒、前部的两根竖杆、底部的滑橇式起落架（4个着地脚）。

材质和配色以图片2为准：防滚架和起落架为黑色哑光钢管；机臂为黑色碳纤维，有细密的碳纤维编织纹理；桨叶为黑色碳纤维；机头整流罩上半部分白色高光烤漆、下半部分深灰色，机头下沿一条细长的白色LED灯带；机尾整流罩白色，带一道细橙色线条；座椅浅灰色，带黑色安全带；侧面深灰色镂空三角板；电机侧面有绿色状态灯。

图片2只用来参考材质、颜色和质感，不要照搬图片2的结构和角度；两张图结构有差异时，一律以图片1为准。

所有logo和文字位置保持底色留空，不生成任何字母或标志。

浅灰色无缝背景，大型柔光箱均匀照明，地面有轻微接地阴影。写实商业产品摄影，高细节，锐利对焦。桨叶静止。
```

### 质检（发给我之前自己先看一遍）
- [ ] 桨是 8 副吗？是上下共轴吗？每副是两叶吗？
- [ ] 机臂是 4 根、横向伸出吗？有没有变成斜着伸出的 X 型？
- [ ] 防滚架的管路走向和图片1一致吗？
- [ ] 底部是滑橇起落架吗？**有没有凭空多出轮子？**
- [ ] 伞舱盒在不在？位置对吗？
- [ ] 配色对吗？机头是上白下深灰，有灯带吗？
- [ ] 有没有生成乱码字母？
